## What Koadr is

Koadr is an open-architecture, agentic AI workspace that turns natural language into production-ready full-stack apps, instantly, inside the browser. It runs a real Node.js stack client-side using WebContainers, so there is no local setup.

A user describes an app in plain language. Koadr plans the stack, writes files, installs dependencies, runs a dev server and shows a live preview in the same tab. The project can then be deployed, exported, or pushed to Git.

## How it differs

- **In-browser runtime:** Node.js, npm and dev servers run client-side via WebContainers rather than in a remote VM.
- **Model-agnostic (BYOK):** 22+ providers, including local models. Keys stay under the user's control; model usage is billed by the provider, never marked up by Koadr.
- **Open architecture and self-hostable:** MIT licensed; the hosted product is optional.

## Features

- In-browser full-stack development (WebContainers)
- Interactive workbench: code editor, terminal, visual diff viewer, live preview
- Smart starters: explicit framework requests select a matching starter with install and dev commands ready
- Prompt library: "Simple Sal" (concise guidance) and "Tiny Tim" (smaller models), under Settings → Workspace → Features
- Project workflows: Git clone/push, snapshot restoration, file conflict locking, codebase search, ZIP export
- Deployments: Netlify, Vercel, GitHub Pages in one click
- Database and visuals: Supabase integration, data visualization charts
- MCP tools and connectors, managed under Settings → Integrations → Connectors
- Cross-platform: native Electron desktop app, Expo / React Native support
- Voice prompting

## Providers

OpenRouter, Anthropic, OpenAI and Google are enabled by default.

## Pricing

- **Free (hosted at koadr.dev):** 0 EUR. Limited cloud-synced projects, storage, history and deployments. Bring your own keys.
- **Pro (hosted at koadr.dev):** 9.90 EUR per month or 99 EUR per year (2 months free on annual). Unlimited projects, unlimited cloud sync and backup, no usage limits, custom domains, priority support.
- **Self-host:** 0 EUR, open source, MIT. Run on your own server; you manage infrastructure and updates.

Koadr is BYOK: you pay your AI provider directly for model usage, never marked up by Koadr.

## Frequently asked

**Do I need my own API keys?** Yes. Koadr is BYOK; you connect provider accounts and pay them directly.

**Can I run fully local models?** Yes, via Ollama or LM Studio.

**Can I switch models mid-project?** Yes, the model is a per-task choice.

**Can I export my projects?** Yes, as a ZIP or by pushing to your own Git repository.

**Do I need to install anything?** No for the hosted app; the runtime runs in the browser. Self-hosting requires Node.js 20+ and pnpm.

**Why pay when it is open source?** Convenience: hosted Koadr works in a few clicks, self-hosting means provisioning and maintaining a server.
